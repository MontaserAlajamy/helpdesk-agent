# Laptop is slow
Arabic: اللابتوب بطيء، الجهاز تقيل، الكمبيوتر بطيء، بيعلق
1. Restart the laptop (not sleep); many slow laptops have not restarted in weeks.
2. Open Task Manager and sort by memory; close browser tabs and apps you are not using.
3. Check free disk space; under 10% free makes everything slow.
4. Install pending updates, then restart again.
Escalate: if it is still slow after these steps, open a ticket (category hardware, priority low) - it may need more memory or a new disk.
