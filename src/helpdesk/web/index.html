How it works

The loop

The model picks a tool, the code checks and runs it, the result goes back, until it calls final_answer or hits the step limit.

Tools

Five typed tools: search the guides, check a service, open or read a ticket, and ask for a restart.

Reading the guides

Fix steps come from the company's IT guides, found by vector search, so the agent does not invent them.

Limits in code

Restarts only queue for a person, tool output is treated as data, and a ticket number the tools did not return is caught.

The exam

24 tasks in English and Arabic check what the agent did, not what it said, and the run fails below the bar.
